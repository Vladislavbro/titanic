### Structure
```
titanic/
├── config.py      # откуда берутся настройки
│                  #   load_config() -> DictConfig  (config.yaml + CLI-оверрайды, read-only)
├── data.py        # откуда берутся данные
│                  #   load_data(cfg) -> X_train, X_test, y_train  (сырые DataFrame, без обработки)
├── features.py    # как данные превращаются в признаки
│                  #   make_features(df, cfg) -> df  (новые колонки и отбор, без обучения, одинаково для train/test)
│                  #   build_preprocessor(cfg) -> ColumnTransformer  (импутация, энкодинг, скейлинг; учится на fit)
├── train.py       # чем и как обучать
│                  #   build_model(cfg) -> необученная модель sklearn
│                  #   build_pipeline(cfg) -> Pipeline(preprocessor + model)
│                  #   cross_validate(pipeline, X, y, cfg) -> метрики CV
└── main.py        # точка входа, своей логики нет, только вызывает остальное по порядку:
                   #   cfg → data → features → pipeline → CV → логирование в wandb
```


### Data
- **PassengerId**: ID пассажира
- **Survived**: выжил (1) или нет (0)
- **Pclass**: класс билета (1, 2, 3)
- **Name**: имя, внутри есть титул (Mr, Mrs, Miss, Master)
- **Sex**: пол
- **Age**: возраст, есть пропуски
- **SibSp**: братья, сёстры и супруги на борту
- **Parch**: родители и дети на борту
- **Ticket**: номер билета
- **Fare**: цена билета, часто за всю группу
- **Cabin**: номер каюты, почти весь пустой, первая буква означает палубу
- **Embarked**: порт посадки: C = Cherbourg, Q = Queenstown, S = Southampton
